# Why AI Has DHH Working 16-Hour Days — 結構化筆記

**基本資訊**：a16z 頻道｜長度 52:15｜來賓：David Heinemeier Hansson（DHH，Ruby on Rails / Basecamp / HEY 創辦人）｜上傳：2026-11-20

## [核心摘要]

AI agent 時代徹底翻轉了作業系統競爭格局：macOS 與 Windows 圍繞滑鼠點擊設計的架構不適合 agent，而 Linux 歷來的「缺點」（終端機依賴、純文字設定檔、詳盡錯誤訊息）恰恰是 agent 最愛的三樣東西 。DHH 據此打造 Omarchy——一個他自己沒寫過一行程式碼、全由 agent 開發的 Linux 發行版，並宣告「原始碼護城河已死」：小團隊兼職兩個半月就能做出與數萬人大廠抗衡的產品。他每天工作 16 小時，是因為完美主義者與品味之間的摩擦力消失了 。

## [詳細重點整理]

### 1. DHH 的背景與轉向 

30 年網路軟體資歷，23 年經營 Basecamp（史上最早的 SaaS 之一），從中抽出 Ruby on Rails，被用於打造 Twitter、GitHub、Shopify、Airbnb 等數百萬應用。五年前推出 HEY 電子郵件服務，著有《Rework》《It Doesn't Have to Be Crazy at Work》等四本書 。

**關鍵概念：典範轉移的連續性**——他不是 AI 新信徒，而是 30 年工匠帶著既有品味進入新典範。

### 2. Omarchy：為 agent 而生的作業系統 

DHH 現在做 Omarchy，自稱「agent 時代的第一個原生作業系統」，目標讓數十萬人從 Windows/Mac 轉向 Linux，讓喊了 25 年的「桌面 Linux 元年」成真 。他 2001 年起是 Mac 死忠，直到 Apple 沉迷於服務收入的 30% 抽成、停止創新並與開發者關係惡化才轉向 。

**關鍵概念：代理原生（agent-native）作業系統**。

### 3. 為什麼 Linux 贏得 agent 時代 

整個 Omarchy 近六個月的開發全部由 agent 完成——DHH 沒有親手寫過任何一行程式碼，卻透過 agent 產出數十萬行。核心論證：

- 過去 40 年作業系統圍繞滑鼠與點擊設計，根本不適用於 agent 時代
- 在 macOS 上想重新映射工作區快捷鍵，只能手動進設定逐一點選；Linux 則一句提示就能改
- Linux 的三大歷史缺點——**重度依賴終端機、難懂的設定檔、詳盡的錯誤訊息**——正是 agent 最愛的三樣東西

**關鍵概念：缺點即優點的反轉**（Linux 的歷史劣勢 = agent 的結構性優勢）。

### 4. Apple 正冒著成為「代理時代的 AOL」的風險 

Apple 提供 Genmoji 這類圍牆花園裡縮水版的 AI，還不斷推出更嚇人的彈出視窗阻止 agent 存取檔案——但 agent 不能存取檔案還能做什麼？25 年來第一次，第三個作業系統的窗口打開了（上一次是 2001 年的 OS X 10.0）。

### 5. 應用程式可得性護城河的瓦解 [00:09:02]

生態系鎖定效應的本質是應用可得性。Omarchy 社群有人花兩週複製出整個 Adobe Lightroom，而且做得比 Adobe 更好——Adobe 花了 15 年與數千萬美元才做到。DHH 的座右銘：「先拿下曼哈頓（桌面），再拿下柏林（行動）」。

**關鍵概念：應用可得性護城河瓦解**。

### 6. Agent 會消滅整個類別的應用程式

DHH 籌設 Omarchy 基金會（已募得約 2,300 萬美元的 token 與捐款），所有合約由 agent 起草、審閱、簽署、寄出，完全不再經過文書處理軟體。Photoshop 不是一個應用，而是一種得花數年精通的職業——現在 agent 全部接手了 。

### 7. 速度決定形態：從 50 到 1,500,000 token/秒 

現在的 AI 每秒約 50 個 token，但 Fireworks 已展示 1,500 token/秒——從提示「幫我做俄羅斯方塊」到遊戲運行只要四秒，且後續修改全部即時變形。DHH 問：兩年後模型每秒跑十萬甚至一百萬 token 時會怎樣？

### 8. 為什麼 DHH 每天工作 16 小時 

DHH 曾寫《It Doesn't Have to Be Crazy at Work》，現在卻承認「工作根本他媽的瘋狂」。原因：從發現問題（差幾個像素）到動手修正之間的障礙完全消失，完美主義者等於突然被賦予超能力。多數 vibe coding 專案死在最初的 80% 之後失去興趣，而他的多巴胺在最後 **2%**——那才是把靈魂注入軟體的地方 。

**關鍵概念：品味即護城河**——軟體的本質是與程式碼行數無關的細微調整（他以《星海爭霸》幽靈特工 20 年來的數值微調為喻）。

### 9. 零協調成本的代理艦隊 [00:19:38]

37signals 維持約 60 人規模。透過 agent 運用 6 萬人的生產力而沒有廢話爭論、沒有人資、沒有委員會——Toby Lütke 稱這種反差為「脫離超光速」。更震撼的是成本：DHH 只有三個 Claude 訂閱，多數週用一個 200 美元的 20 倍方案就完成所有事 。

**關鍵概念：零協調成本的代理艦隊**。

### 10. 軟體開發已經有超級智慧

把能力廣度與速度加總，AI 已比 DHH 認識的任何程式設計師都強（只在極窄領域頂尖人類仍能勝出）。有趣的對比：矽谷軟體人認為明年就有 ASI，而 DHH 在宇樹科技聽到的時間線是四、五年甚至十年——機械與致動器的摩爾定律完全不同 。

### 11. 前沿實驗室與開放權重的制衡 

DHH 主張兩邊都要：為前沿進展喝采，同時需要開放權重模型制衡，否則就是 90 年代加密戰爭與 Google/Meta 雙頭壟斷的重演——一家公司攫取所創造價值的 99% 是反烏托邦 。

### 12. 本地端 AI 的實用化 

六個月前 DHH 還寫文說買高速 PC 跑本地模型很蠢——他坦承完全錯了。現在 DGX Spark 已能跑出真正可用的模型（如 Qwen 3.8 Flash Next），幾千美元就能把智慧放在桌上的盒子裡。開放權重模型（GLM 5.3、DeepSeek Flash）約落後前沿六、七個月，某些任務上甚至沒落後 。

### 13. 野心通膨與「三年超越 macOS」 

專案去年以純手工 bash 腳本起頭，只為自己做台好電腦。agent 出現後，野心從「稍微好一點的電腦」通膨為「完美的電腦」。目前妄想：三年內比 macOS 更大——全世界只有 1.8 億個 macOS 使用者，連一個 C 級網路服務都不到 。

### 14. 對受威脅工程師的同理與「氛圍之戰」 

多數程式設計師沒有財富自由，靠辛勤積累的技能換得一席之地，突然焦慮萬一明天一切消失怎麼辦。DHH 主張對這種心情抱持同理（如同情七〇年代底特律汽車工人與盧德派），但前進的路只有一條：穿越它。同時點出現實：他敬佩的所有頂尖駭客——Carmack、Tim Sweeney、Mitchell Hashimoto——百分之百已全力投入 。

**關鍵概念：氛圍之戰（vibes war）**。

### 15. 半匿名駭客與 Demo 文藝復興

Omarchy 核心團隊裡有兩位半匿名成員：outfoxxed（Quickshell 創作者）與 handcore（藝術家）。Omarchy 基金會也贊助半匿名的 0x0 與 Mia's lab。九〇年代 demo 文化正在回歸——Omarchy 招牌的 ASCII 藝術螢幕保護程式跑過 40 種 demo 特效，本地 AI 模型載入時也播放純裝飾的 ASCII 動畫。DHH 批評 Jony Ive 用鋁金屬把電腦的個性拋光掉了：「電腦應該有點神祕，應該要很酷」 。

**關鍵概念：半匿名駭客文藝復興**。

## [結論與行動建議]

**啟發金句**：「未來已經來臨，只是分布得不均勻。」（William Gibson，DHH 唯一願意背書的預測框架）

**具體行動建議——V-C-C 法則（Vision–Craft–Cost）**：

1. **Vision（願景先行）**：先決定你要的完美終點，再讓 agent 路徑規劃——願景無法被代工
2. **Craft（死磕最後 2%）**：初始 80% 人人都做得出來，真正的差異化與多巴胺在最後 2% 的細節打磨
3. **Cost（成本覺察）**：頂級生產力不需要無限預算——每月 200 美元的訂閱就能驅動整個發行版等級的專案，別讓「我沒資源」成為不開始的藉口

**生活實踐建議**：

- 把日常工作流中最繁瑣的重複任務（合約審閱、文件轉檔、照片修圖）逐一交給 agent，像 DHH 完全繞過文書處理軟體那樣，重新設計你的工具鏈
- 若你在評估開發環境：Linux 的終端機、純文字設定檔與詳盡錯誤訊息正是 agent 的最佳介面，值得用虛擬機或備用機實際體驗「沉浸五分鐘」
- 面對身邊對 AI 焦慮的同儕，採取 DHH 的「同理但不退讓」立場：承認失落感是真實的，但前進的唯一路徑是穿越它，不是抵抗它
