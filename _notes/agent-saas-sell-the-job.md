## 核心摘要

這部影片提出「**Agent SaaS**」的全新商業模型：傳統 SaaS 賣的是工具軟體，而 Agent SaaS 賣的是「工作本身」——直接把原本由員工執行的整個工作流程，包裝成可付費委外的服務 。影片解決的痛點是多數人只看到 AI Agent 的技術可能性,卻不知道如何將其轉化為可規模化、可收費的商業產品；作者提供了一套從找利基、影子觀察人類工作者、打造最小可用 Agent、到銷售與規模化的完整七步驟劇本，並附上 30 天啟動計畫 。 [youtube](https://www.youtube.com/watch?v=YeamHE6Kank)

## 詳細重點整理

### 1. 產品即工作 [01:38]
核心心智模型是「SaaS 賣軟體，Agent SaaS 賣工作」——不再是提供工具讓團隊使用,而是直接告訴客戶「這項工作你的團隊不再需要親自做」,並將其作為服務出售 。作者以餐廳電話代接（Slang AI）與居家服務派工（Same Day）為例,說明產品必須比初階員工做得更好、比代理商更快、比增加人力更便宜。關鍵概念：**工作即產品（Product Is the Job）**。 [youtube](https://www.youtube.com/watch?v=YeamHE6Kank)

### 2. 挑選帶薪水的工作流程 [04:11]
好的 Agent 工作流程需具備五大特徵：高頻率發生、有明確完成終點、已連結現有軟體工具、邊緣案例可學習、買方能真實感受到痛點 。作者建議的第一個練習是選定一個利基,列出 20 項該產業常見抱怨的工作,並依頻率、痛感、清晰度、工具需求與預算擁有者五個維度評分。關鍵概念：**帶薪水的工作流程（Workflow With a Paycheck）**。 [youtube](https://www.youtube.com/watch?v=YeamHE6Kank)

### 3. 先觀察人類再動手 [06:12]
在寫任何 Prompt 或程式碼之前,必須先觀察一位真實執行該工作的人操作 10 到 20 個案例,並要求對方錄影與口述講解 。目標是挖掘隱藏的判斷邏輯——如何辨別特殊案例、錯誤發生在哪裡；隨後將 Agent 拆解為七個規格要素:觸發條件、上下文、工具、可執行動作、需人工核准點、升級條件與成功定義。關鍵概念：**細節即產品（The Detail Is the Product）**。 [youtube](https://www.youtube.com/watch?v=YeamHE6Kank)

### 4. 打造最小可用 Agent [09:34]
作者提出四種第一版 Agent 型態：草稿待核准型、分類分派型、協調者型、有限動作型,建議從最小版本開始,而非追求完全自主的「員工級」Agent 。他引用 Anthropic 的建議——多數 Agent 問題應先從可預測的工作流程開始,再逐步透過判斷力增加自主性。關鍵概念：**最小可用 Agent（Minimum Useful Agent, MUA）**。 [youtube](https://www.youtube.com/watch?v=YeamHE6Kank)

### 5. 包裝層才是真正的 SaaS [12:50]
Agent 負責執行工作,但「包裝層」——日誌記錄、核准機制、控制項、交接規則——才是建立客戶信任、讓自動化真正變成 SaaS 產品的關鍵 。作者強調建立包含 50 個真實案例的評測集（Eval Set）,像健身房一樣持續檢驗 Agent 表現,這同時也是強大的銷售資產。關鍵概念：**評測驅動信任（Eval-Driven Trust）**。 [youtube](https://www.youtube.com/watch?v=YeamHE6Kank)

### 6. 把試營運當人力銷售 [15:50]
最快的路徑是先以人力+AI 手動執行試營運,再將重複模式產品化;建議先在同一利基找三個客戶,收取設定費加月費的簡單定價,再逐步導入使用量或成果計價 。作者相信成果計價（Outcome Pricing）是 Agent 優先軟體未來的主流定價方式。關鍵概念：**成果計價（Outcome Pricing）**。 [youtube](https://www.youtube.com/watch?v=YeamHE6Kank)

### 7. 掌握工作流程與流量策略 [18:37]
規模化的關鍵是找出每個客戶都需要的重複模式（例如屋頂工程業者都需要緊急電話腳本、服務區域檢查、融資問答等）,一旦模式重複出現即可產品化 。流量策略上,作者強調「工作流程拆解對比」內容最有效——展示舊方式的痛點,再展示 Agent 方式的流暢,賣的是止痛藥而非維他命。關鍵概念：**工作流程拆解（Workflow Teardown）**。 [youtube](https://www.youtube.com/watch?v=YeamHE6Kank)

### 8. 30 天從零到百的計畫 [21:45]
第一週：選利基、訪談 10 位操作者、選定單一工作流程、撰寫 Agent 規格、手動用 AI 執行測試、建立最小版本、產出 50 例評測集;第二週銷售兩個試營運案;第三週加入產品包裝層（日誌、核准、分析）;第四週發布工作流程拆解內容,將試營運轉化為證明素材並強化內容策略 。關鍵概念：**零到百計畫（Zero-to-100 Plan）**。 [youtube](https://www.youtube.com/watch?v=YeamHE6Kank)

## 結論與行動建議

**啟發金句**：「軟體正從『幫你做』轉變為『和你一起做』——找到那個每天不斷重複的痛點工作流程,讓它徹底消失。」 [youtube](https://www.youtube.com/watch?v=YeamHE6Kank)

**具體行動建議**——**S-S-P 法則**：Shadow（先觀察真人操作 10–20 次）→ Spec（拆解成七要素規格書）→ Pilot（以人力+AI 方式先銷售試營運再產品化）。

**生活實踐建議**：即便不創業,身為產品經理也可將此框架套用於內部流程優化——先觀察現有人工作業的隱藏邏輯,再用最小可用 Agent 處理高頻率、低判斷力的工作環節（如客服分類、報告草稿),逐步建立信任機制後才擴大自主範圍。
