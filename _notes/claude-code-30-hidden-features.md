## [核心摘要]

Claude Code 官方文件中藏有上百個功能，多數使用者只用到冰山一角。本影片實測全部功能後，精選 30 個最實用的隱藏技巧，涵蓋四大類痛點：**提示詞編輯中斷**（暫存、外部編輯器）、**工作時的等待浪費**（背景執行、訊息佇列）、**輸入框操作效率**（kill ring 復原、路徑批次刪除），以及**對話與模型管理**（回溯還原、代理檢視）。核心貢獻是將終端機工作流壓縮到零切換、零等待 。

## [詳細重點整理]

### 一、提示詞編輯類

1. **暫存提示詞**  
寫到一半想先問別的事，按 Ctrl + S（stash），輸入框清空、右下角出現 stash 圖示。送出問題後，暫存文字**自動回到輸入框**，無需任何額外按鍵。關鍵概念：**提示詞暫存（Prompt Stash）** 。
2. **外部編輯器編輯**   
按 Ctrl + E 用系統預設編輯器（Nano / VS Code / Vim）打開提示詞，讀取的是終端機的 `EDITOR` 環境變數。Nano 以 Ctrl + X → Y → Enter 存檔回填；Vim 則是 Esc → `:wq` → Enter。通用替代方案：先按 Ctrl + X 再按 Ctrl + S（Bash 使用者熟悉的組合）。關鍵概念：**EDITOR 環境變數** 。
3. **換行不送出**  
在終端機輸入框 Enter 會直接送出，半句話常被截斷。改用 Ctrl + J 換行不送出，任何終端機都有效；替代方案是在行尾打反斜線 `\` 再按 Enter。關鍵概念：**換行與送出分離** 。

### 二、背景執行與佇列類

4. **任務轉背景執行 \[02:28\]**  
長時間測試（例如 15 個案例 × 2 秒 = 30 秒）跑到一半按 Ctrl + B，任務轉入背景，輸入框立刻空出可繼續提問；跑完後 Claude 主動通知並回報結果，介面下方的「BG」標示背景任務數量。關鍵概念：**背景執行（Background Execution）** 。
5. **訊息佇列 \[03:05\]**  
Claude 工作中直接按 Enter，請求自動排進佇列；若輸入框出現自動完成建議，先按 Ctrl + X 再按 Enter（三秒內完成兩步）即可跳過建議直接排隊。排錯了按上方向鍵，訊息回到輸入框修改重排。若想立刻得到答案，排隊問題會優先被回答，正在跑的任務自動轉背景——**不必等任務結束**。關鍵概念：**訊息佇列（Message Queueing）** 。
6. **緊急煞車：終止所有子代理**   
子代理（subagent）派太多或方向錯誤時，連按兩次即可全部停止——第一次會跳出確認提示，再按一次全部終止。關鍵概念：**子代理緊急煞車** 。
7. **暫停 Claude Code \[04:18\]**  
按 Ctrl + Z 將 Claude Code 掛起、回到一般終端機跑指令，用完輸入 `fg`（foreground）即原封不動恢復。僅限 Mac 與 Linux；首次按下時系統會提醒：Ctrl + Z 是掛起，Ctrl + 底線才是復原。關鍵概念：**工作階段掛起（Suspend）** 。

### 三、對話框與快速提問類

8. **核准時直接附加修改**   
Claude 修改檔案前的核准對話框，多數人只選「是／否」。切到手動模式（Shift + Tab）後按 Tab，可在「是」後面直接加上修改要求——Claude 照原計畫建立檔案後再套用修改，**省掉重新解釋需求的一輪**。關鍵概念：**核准即編輯（Approve-and-Edit）** 。
9. **BTW 浮動問答與分支代理**  
「by the way」快速提問的答案出現在浮動視窗，不存入對話紀錄、不佔上下文，只依現有對話內容回答、不讀檔案不執行指令。搭配兩個隱藏鍵：一鍵將答案以原始 Markdown 複製到剪貼簿；另一鍵將問答**分支成背景代理（agent）**，帶著完整對話並額外獲得工具使用能力。關鍵概念：**上下文零佔用（Zero-Context）** 。

### 四、輸入框編輯類

10. **復原（Undo）**  
終端機裡 Ctrl + Z 不是復原；真正的復原鍵是底線，需搭配 Shift，實際組合為 **Ctrl + Shift + 減號**。刪掉的指令回來後游標停在原位。關鍵概念：**Readline 復原** 。
11. **批次刪除與 Kill Ring**  
Ctrl + W 刪到前一個空格（無視斜線與句點），16 字元的路徑 `src/utils/vue.ts` 一鍵清掉；Ctrl + U 刪整行、Ctrl + K 刪到行尾。所有被刪內容都進入 **kill ring**，按 Ctrl + Y 隨時貼回，刪除後右下角也會提示。關鍵概念：**Kill Ring** 。
12. **雙擊 ESC 清空與草稿保存**   
輸入框有文字時快速連按兩下 ESC 才會清空；被清掉的草稿依官方文件會存入歷史紀錄，可找回。Ctrl + C 在無任務執行時也是清空輸入框，之後在**空輸入框按上方向鍵**即可找回草稿（新版功能，示範版本 2.1.296）。關鍵概念：**草稿歷史（Draft History）** 。
13. **表情符號自動完成**   
輸入 `:rocket:` 自動轉為 🚀，寫 commit 訊息或 changelog 時好用。記不得全名可打冒號加兩個字母叫出建議，方向鍵選擇、Tab 插入。注意：必須逐字輸入，貼上的不會生效。關鍵概念：**Emoji 補全** 。
14. **問號叫出快捷鍵清單**   
輸入框為空時按 `?` 顯示完整快捷鍵清單（模式切換、清空、暫存、編輯器等）；輸入框有文字時按 `?` 只會打出問號。忘了任何快捷鍵，按問號即可。關鍵概念：**內建速查表** 。
15. **斜線指令句中補全**   
斜線指令（slash command）不必放在開頭：句中打空格 + 斜線 + 幾個字母即出現自動完成，Tab 補完。但**指令只有放在句首才會執行**，放中間只是文字，Claude 只會看到你「提到」了它。關鍵概念：**句首執行規則** 。
16. **命令列模式與指令補全**   
輸入框第一個字元打 `!` 進入**命令列模式**（command line mode），內容直接作為終端機指令執行、不經過 Claude，輸出自動進入對話讓 Claude 查看。跑測試或看 git status 最快。隱藏功能：命令列模式下按 Tab，可從本專案跑過的指令自動補全。關鍵概念：**Shell 直通模式** 。
17. **幽靈文字建議**   
Claude 回覆後輸入框偶爾出現灰色文字，是它猜你接下來要說的話：按 Tab 或右方向鍵填入再送出；直接打字則消失。非每次出現，出現時再用即可。關鍵概念：**幽靈文字（Ghost Text）** 。

### 五、模型與對話管理類

18. **模型選擇器與思考強度**  
輸入框有文字時按 Option + M（Windows / Linux 為 Alt + M）叫出模型選擇器，文字不會被清掉。倒數第二行是 **effort（思考強度）等級**，左右方向鍵調整，等級越高思考越久、適合難任務。按 Enter 設為永久預設；按小寫 `s` 只套用本次工作階段、重啟後恢復、不動全域設定。不帶參數輸入指令則叫出滑桿，同樣按 `s` 套用當次。關鍵概念：**Effort 等級** 。
19. **Ultracode 隱藏開關**   
模型選單右側分頁有一個名為 **ultracode** 的隱藏開關：開啟後每個任務自動派多個代理並行處理，適合大型任務，但會消耗大量用量。關鍵概念：**多代理並行（Multi-Agent Parallelism）** 。
20. **回溯（Rewind）還原**  
輸入框為空時連按兩下 ESC 跳出回溯選單，列出每一則送出訊息；選一則，**對話與程式碼同時還原到該時間點**。Claude 改壞東西時，退回改動前一步即可。關鍵概念：**時間點回溯（Rewind）** 。
21. **全螢幕詳細紀錄 \[11:59\]**  
Ctrl + O 打開詳細紀錄，可見 Claude 呼叫的工具、執行的指令、每次回覆用的模型。裡面按 `?` 顯示隱藏按鍵：大括號在過去提示詞間跳轉、斜線搜尋、編輯器開啟診斷對話、按 V 最方便複製整理 Claude 說過的內容。關鍵概念：**診斷紀錄（Verbose Log）** 。
22. **提示詞歷史搜尋**  
Ctrl + R 搜尋過去送出的提示詞，關鍵字即中。搜尋框內按 Ctrl + S 切換範圍：所有專案 / 只搜本對話 / 只搜本專案；按 Enter 拉進輸入框修改後重送。關鍵概念：**跨專案提示詞檢索** 。
23. **整頁捲動與追蹤**  
全螢幕模式下按 Fn + 方向鍵整頁捲動（MacBook 無 Page 鍵，Fn 即等於 Page Up / Down）。往上捲後新輸出不會把你拉回底部；底部「Jump to bottom」按鈕回到最新位置後畫面自動跟捲。外接鍵盤：Ctrl + Home 跳開頭、Ctrl + End 跳最底。關鍵概念：**捲動鎖定（Scroll Lock）** 。
24. **變更面板與基準切換**  
側邊變更面板列出 Claude 改了哪些檔案、新增與刪除行數。按 Ctrl + X 再按 B 切換比較基準：本次對話的變更 / 所有未提交變更 / 整個分支變更，且會**記住每個儲存庫的選擇**。關鍵概念：**變更基準（Diff Baseline）** 。
25. **代理檢視管理所有對話**  
游標在輸入框時按左方向鍵進入**代理檢視（agent view）**：開著的對話依狀態排序，一眼看出哪些等你回覆、哪些在跑、哪些完成；對話只是移到背景，並未關閉。Ctrl + S 切換依狀態或依專案分組、Ctrl + T 釘選常用對話、Ctrl + F 用名稱找對話、Ctrl + R 重新命名對話（與第 22 點的搜尋不同）。關鍵概念：**代理檢視（Agent View）** 。
26. **版本要求**  
多個功能很新，需先更新到最新版；示範版本為 0.40.4，比它新的皆可。最推薦先上手的兩個：Ctrl + S 暫存與 Ctrl + X → Ctrl + S 佇列，「用過就回不去了」。此為講者可能的最後一支 Claude 教學（帳號因素），之後轉向其他 AI 工具分享 。

|---|---|

## 五、模型與思考強度（22–24）
