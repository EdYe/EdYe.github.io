### **核心摘要**

本影片深入解析 Claude Code 內建的隱藏子代理 **「@claude-code-guide」**，展示如何透過五個層次從基礎問答到自動修復程式碼，將其轉化為開發者的私人 AI 顧問。

---

### **詳細重點整理**

#### **1. 認識 @claude-code-guide：你的專屬技術顧問**

* **功能定義**：它是 Claude Code 內建的一個子代理（Sub-agent），專門精通 Claude Code 的所有指令、掛鉤（Hooks）與文件。
* **優勢**：在詢問它時，它會檢索自身的指南文件，這**不會消耗**你主對話的上下文視窗（Context Window），保持開發過程的高效。

#### **2. 第一、二層級：基礎問答與 CLAUDE.md 診斷**

* **基礎查詢**：可以詢問如「如何在會話中更換模型」或「CLAUDE.md 如何運作」等概念性問題，它會提供權威的官方解答。
* **優化指令**：你可以標記當前的 `CLAUDE.md` 檔案，問它：「為什麼我的設定沒效？」它會診斷缺少的關鍵指令、程式碼格式要求或組織規則，並提供修改建議。

#### **3. 第三層級：深入學習 Hooks 機制**

* **理解自動化**：詳細列出 Claude Code 支持的 **17 種 Hook 事件**（如：會話開始前、工具使用後等）。
* **排除障礙**：解決非技術人員或新手在處理 JSON 格式與自動化觸發時的學習困難。

#### **4. 第四層級：自定義斜線指令 (/commands)**

* **實作演示**：透過引導，讓 AI 幫你建立自定義的 `/standup` 指令，將繁瑣的重複性任務（如總結當前工作狀態）自動化。

#### **5. 第五層級：自動修復與診斷系統 (Self-heal)**

* **高階應用**：當系統中的 Hook 出現錯誤或檔案命名混亂（如影片中隨機生成的動物名稱檔案）時，直接標記受損檔案並要求引導程序修復。
* **成果**：AI 會閱讀文件、診斷錯誤（例如路徑缺失）、撰寫修復計畫並執行重構，實現真正的「自癒」開發環境。

---

### **結論與行動建議**

* **金句啟發**：「有時候最簡單的解決方案，只要正確使用，就是最強大的工具。」
* **具體建議**：
1. **停止 Google**：遇到 Claude Code 的操作疑問時，優先使用 `@claude-code-guide` 提問。
2. **定期診斷**：每隔一段時間將 `CLAUDE.md` 交給指南代理檢查，確保開發規範與時俱進。
3. **善用標記**：在提問時同時標記（Tag）相關檔案，能讓 AI 提供更具上下文相關性的精準修復方案。
