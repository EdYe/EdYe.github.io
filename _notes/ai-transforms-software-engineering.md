這部影片由 *Lenny's Podcast* 主持，邀請到 Anthropic 的 Claude Code 負責人 **Boris Cherny**，深入探討 AI 如何徹底改變軟體工程，以及當「程式碼編寫」被解決後，技術領域的下一個大轉移是什麼。

### 核心摘要

這部影片探討了 AI（特別是 Claude Code）如何讓工程師從瑣碎的編碼中解脫，並預測軟體工程將轉向以「構思與建造」為核心的通用型角色，而非單純的程式編寫。

---

### 詳細重點整理

#### 1. 軟體工程的典範轉移：編碼已成「已解決」的問題

* **100% AI 生成**：Boris 分享他自 2024 年 11 月以來，未曾親手寫過一行程式碼，所有內容均由 Claude Code 完成 [[00:00](http://www.youtube.com/watch?v=We7BZVKbCVw&t=0)]。
* **生產力激增**：在 Anthropic 內部，人均工程師的生產力提升了 200%，Boris 本人每天能發送 10 到 30 個 Pull Requests (PR) [[16:46](http://www.youtube.com/watch?v=We7BZVKbCVw&t=1006)]。
* **職位轉型**：他預測「軟體工程師」這一頭銜將逐漸消失，取而代之的是「建造者 (Builder)」。到 2025 年底，每個人都可能是產品經理，且每個人都能編寫程式碼 [[00:44](http://www.youtube.com/watch?v=We7BZVKbCVw&t=44)]。

#### 2. Claude Code 與 Co-work 的開發內幕

* **終端機優先的設計**：Claude Code 最初是作為終端機工具開發的，因為模型進步速度太快，只有文字介面能跟上模型的演進頻率 [[10:40](http://www.youtube.com/watch?v=We7BZVKbCVw&t=640)]。
* **從編碼到代理人 (Agents)**：AI 不再只是對話夥伴，而是能使用工具、讀取 bug 報告並主動修復問題的「同事」[[03:30](http://www.youtube.com/watch?v=We7BZVKbCVw&t=210)]。
* **快速迭代**：Boris 提到 Co-work 產品（讓非技術人員也能自動化任務）僅用了 10 天就開發完成，且完全是利用 Claude Code 來編寫的 [[52:02](http://www.youtube.com/watch?v=We7BZVKbCVw&t=3122)]。

#### 3. 給團隊與產品開發者的建議：擁抱「不對稱性」

* **過度資源化不如「低度資助」**：給予團隊較少的人力，但提供無限的 AI Token，會激發工程師利用 AI 自動化流程的本能，進而產生創新 [[24:24](http://www.youtube.com/watch?v=We7BZVKbCVw&t=1464)]。
* **為「未來六個月」的模型而建**：開發產品時，不應針對當前模型的能力設限，而應預測六個月後模型的進步程度（如更長的運行時間、更強的工具使用能力）進行設計 [[01:05:56](http://www.youtube.com/watch?v=We7BZVKbCVw&t=3956)]。
* **不要試圖限制模型**：與其設計嚴格的 Step-by-step 工作流，不如給模型工具與目標，讓它自行尋找解決路徑，這通常能獲得更好的結果 [[01:03:47](http://www.youtube.com/watch?v=We7BZVKbCVw&t=3827)]。

#### 4. 未來的技能需求：通才的崛起

* **跨領域能力**：未來的成功者將是那些能跨越設計、產品、工程與商業邏輯的通才。AI 降低了技術門檻，因此「溝通需求」與「判斷什麼值得建造」變得比「如何建造」更重要 [[41:08](http://www.youtube.com/watch?v=We7BZVKbCVw&t=2468)]。
* **歷史類比**：Boris 將 AI 浪潮比作印刷術的發明，它讓原本掌握在少數「抄寫員」手中的技能（讀寫/編碼）民主化，進而可能引發新的文藝復興 [[32:54](http://www.youtube.com/watch?v=We7BZVKbCVw&t=1974)]。

---

### 結論與行動建議

* **具體建議**：如果你想在 AI 時代保持領先，請成為一名**「實驗者」**。不要害怕技術退化，而是要學習如何指揮多個 Agent 同時協作 [[01:00:12](http://www.youtube.com/watch?v=We7BZVKbCVw&t=3612)]。
* **啟發性金句**：**「我從未像今天這樣享受過編碼，因為我不再需要處理所有的細枝末節。」** [[00:10](http://www.youtube.com/watch?v=We7BZVKbCVw&t=10)]
* **實操技巧**：使用 Claude Code 時，強烈建議開啟 **Plan Mode**（計畫模式），讓模型先思考邏輯再執行，這能大幅提升一次性成功的機率 [[01:09:52](http://www.youtube.com/watch?v=We7BZVKbCVw&t=4192)]。
