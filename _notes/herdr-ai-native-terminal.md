## [核心摘要]

Herdr 是一款「AI 原生」的終端機多工管理器，定位為 tmux 的現代化繼任者：它以背景伺服器架構讓終端機、視窗、窗格與 AI 代理工作階段永久存活（detach 後不中斷、重開機後自動復原），並內建代理狀態通知（完成／受阻／工作中）、依狀態篩選、代理可透過 API/技能反過來操控 Herdr，甚至讓不同機器上的代理彼此對話。它解決的痛點是：多代理並行工作時的監控、協調與跨裝置接續問題。

## [詳細重點整理]

1. 開場：AI 原生的終端機  
Herdr 像 tmux 一樣在一台機器上啟動、開窗格、跑多個 AI 代理，再從任何裝置（如筆電）連回，體驗如從未離開。它是滑鼠優先的終端機，但同時保留完整的鍵盤快捷鍵。核心差異在於代理完成、卡住或出錯時會主動發出**通知（toast + 音效 + 圖示）**，並可依狀態快速篩選工作階段。  
關鍵概念：**AI 原生終端機（AI-native terminal）**
2. 安裝與首次設定   
到 [herdr.dev](http://herdr.dev) 取得安裝指令，支援 macOS、Linux 與 Windows（PowerShell 指令）。輸入 `herdr` 即進入介面，全程可用滑鼠操作；鍵盤派可用 `Ctrl+B` 進入**前綴模式（prefix mode）**。首次啟動時可安裝 AI 整合（示範中自動偵測到 Claude 與 Hermes），並可開啟 toast 通知、音效與主題。  
關鍵概念：**前綴模式（Prefix Mode）**
3. 伺服器架構：工作不會死  
在窗格內跑 `ping 1.1.1.1`，按 `Ctrl+B`、`Q` 分離後終端機消失，再輸入 `herdr` 重新進入，程序仍在跑。Herdr 本質是**背景伺服器（server）**，所有終端機、視窗、窗格與代理都活在伺服器裡；即使伺服器被停掉（`herdr server stop`）或電腦重開機，重新啟動後所有工作階段都會復原。  
關鍵概念：**工作階段持久化（Session Persistence）**
4. 窗格、分頁與工作區三層結構   
窗格（pane）：`Ctrl+B`、`V` 垂直分割；`Ctrl+B`、`-` 水平分割；`Ctrl+B`、`Shift+P` 重新命名；`Ctrl+B`、`R` 進入調整大小模式（H/J/K/L）；`Ctrl+B`、`X` 關閉。  
分頁（tab）：`Ctrl+B`、`C` 新增；`Ctrl+B`、`Shift+T` 重新命名；`Ctrl+B`、`P`/`N` 切換上下一個。  
工作區（workspace）：`Ctrl+B`、`Shift+N` 新增；`Ctrl+B`、`Shift+W` 重新命名；`Ctrl+B`、`W` 快速切換；`Ctrl+B`、`Shift+D` 關閉。窗格 &lt; 分頁 &lt; 工作區三層結構用於組織，且全部可用滑鼠操作。  
關鍵概念：**三層容器結構（Pane–Tab–Workspace）**
5. 全域導覽與代理狀態篩選  
`Ctrl+B`、`G`（go to）開啟全域檢視，用方向鍵或 HJKL 瀏覽所有工作區、分頁、窗格與代理。代理面板會依工作區標示所屬位置，並可透過**篩選器**快速定位：`D` = 完成（done）、`B` = 受阻（blocked，等待你回答問題）、`W` = 工作中（working）、`I` = 閒置（idle）、`A` = 全部（all）。也可按 `/` 用關鍵字搜尋工作階段名稱與內容。`Ctrl+B`、`?` 可查詢所有按鍵綁定並支援搜尋。  
關鍵概念：**代理狀態篩選（Agent State Filtering）**
6. 通知系統  
進入設定（`Ctrl+B`、`S`）開啟音效與 toast 通知後，任何代理完成或需要你回覆時，會立刻跳出通知。這讓你敢於「離開終端機」去處理別的事，把代理人當成非同步的隊友而非需要盯著看的程序。  
關鍵概念：**非同步代理協作（Asynchronous Agent Orchestration）**
7. 遠端 Herdr   
用 `herdr machine add --label Big Mac networkchuck@10.77.14.204` 即可把另一台機器（需已裝 Herdr 且可 SSH 連線）的 Herdr 工作階段掛進本機介面，統一收到遠端通知、統一用 `Ctrl+B`、`G` 切換，效果如同本地操作。  
關鍵概念：**遠端機器聚合（Remote Machine Federation）**
8. 代理操控 Herdr   
Herdr 提供**技能（skill）／API／CLI**，讓 AI 代理能反過來操控 Herdr：示範中要求 Claude 代理「開五個窗格」，它直接辦到；代理也會自己重新命名窗格、讀取其他窗格的回覆內容。這代表代理具備對終端機環境的「自覺」，知道自己在哪個窗格、哪個工作區。  
關鍵概念：**代理環境自覺（Agent Environment Awareness）**
9. 代理互相對話   
主控 Claude Code 可開四個窗格分別跑 Codex、Grok、Antigravity 與另一個 Claude 工作階段，指派協作任務（如共同製作《哈利波特》ASCII 動畫場景）。Herdr 內建**掛勾（hook）**機制：任何子代理完成、出錯或有狀況時會自動回報主控代理，形成多代理協作迴圈。甚至可跨機器：本機代理透過遠端 Herdr 跟另一台機器上的代理對話並取回答案。  
關鍵概念：**多代理掛勾回報（Multi-Agent Hook Reporting）**
10. Git 工作樹整合與伺服器復原  
代理可透過 Herdr 建立 **Git 工作樹（worktree）**，用 Gemini、Claude、Codex 三個代理分頭開發同一個專案的不同分支再提交，過程中可用 `Ctrl+B`、`G` 觀看各代理的工作狀態。最後示範 `herdr server stop` 後重進，所有工作階段（含代理對話內容）即刻復原。  
關鍵概念：**代理並行工作樹（Parallel Agent Worktrees）**

## [結論與行動建議]

啟發金句：  
「不要害怕 AI——它不會取代你，它會讓你變得更好；你缺的從來不是技能，是時間。」

具體行動建議（D-G-P 法則）：

- **D**etach（分離）：把長時間執行的代理與程序丟進 Herdr，離開終端機去生活
- **G**o-to（巡視）：固定用 `Ctrl+B`、`G` + 狀態篩選（D/B/W）掃描所有代理進度
- **P**air（配對）：讓主控代理透過 hook 指揮多個子代理並行工作，你只處理「受阻」項目

生活實踐建議：

- 將不同專案拆成獨立工作區（如「AI 開發」、「影片製作」），每個工作區放對應的 Claude Code / Codex / Gemini 代理，通勤或在外時從筆電甚至手機 App 連回家中主機接續工作。
- 執行批次任務（例如影片逐字稿整理、資料爬梳、程式碼重構）時，一次開多個代理平行處理，只回頭處理「blocked」篩選出的待答項目，把監控成本降到趨近於零。
- 網路工程情境：把翻日誌、找斷線根因、產生文件與架構圖這類重複工作交給代理在 Herdr 中背景執行，自己專注在需要判斷力的決策上。
