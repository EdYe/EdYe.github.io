# Claude Cowork 工具組：12 個進階提示詞，取代一週的工作量

Claude 全新的 Cowork 功能徹底改變了工作方式。它能存取你的檔案、在背景運行，並實際產出成果——而不只是告訴你該怎麼做。這 12 個提示詞能讓你立即上手。

---

## 如何使用這套工具組

**必要條件：**

* Claude Max 訂閱方案
* Claude 桌面應用程式（目前僅支援 Mac）
* 已準備好授權 Cowork 存取的檔案或資料夾

**每個提示詞的使用步驟：**

1. 開啟 Claude 桌面應用程式，點擊「Cowork」分頁
2. 新增相關資料夾或連接器
3. 貼上並自訂提示詞
4. 點擊「Let's go」並視需要授予權限
5. 讓它執行——Cowork 在處理時，你可以同時進行其他工作

> 💡 **專業提示：** Cowork 在本機運行，即使你切換應用程式或關閉瀏覽器分頁，進度也不會中斷。

## 提示詞 1：內容成效分析器

**使用情境：** 你擁有數月（或數年）的內容數據，想知道哪些內容真正有效——以及原因。

**主要輸入資料：**

* 包含分析匯出資料的資料夾（CSV、Excel）
* 包含內容檔案或逐字稿的資料夾（非必要，但建議提供）
* 你的主要目標（訂閱數、潛在客戶、營收等）

**預期產出：** 一份包含成效模式、頂尖內容分析與策略建議的簡報檔案。

### 提示詞 1：內容成效分析器

```
我將授予你存取以下兩個資料夾的權限：

1. [分析資料夾] — 包含我的內容成效數據

2. [內容資料夾] — 包含實際內容或逐字稿

我的主要目標是：[目標 — 例如：「增加 YouTube 訂閱數」、「產生行銷合格潛在客戶」、「提高電子郵件開信率」]

請綜合分析數據與內容，找出：

- 哪些內容最能達成我的目標（以及原因）
- 主題、格式和發布時間與成功的相關模式
- 成效不佳、應下架或更新的內容
- 應填補的新內容缺口

然後建立一份簡報，包含：

- 研究摘要
- 前 5 名表現最佳的內容，並分析其成功原因
- 下一季的內容策略建議
- 根據所發現的模式提出的具體內容創意

請讓這份簡報達到可直接呈現的水準——我希望無需修改即可向團隊或主管展示。
```

## 提示詞 2：批次文件生成器

**使用情境：** 你需要建立多份相似的文件（職缺描述、標準作業程序、電子郵件序列等），且不想逐一處理。

**主要輸入資料：**

* 參考文件或範本（如有）
* 所需文件清單（或建立標準）
* 相關背景資料檔案

**預期產出：** 一個包含所有完成文件的資料夾，可直接使用。

### 提示詞 2：批次文件生成器

```
我需要建立 [數量] 份 [文件類型 — 例如：「職缺描述」、「標準作業程序」、「產品說明頁」]。

以下是我授予你存取的資料：
- [資料夾] 包含參考文件或範本
- [資料夾或檔案] 包含所需建立的清單或標準

每份文件請包含：
[列出必要段落 — 例如：「職位摘要、主要職責、必要資格、加分條件、薪資範圍」]

請以我現有文件作為風格指南——匹配語氣、格式與細節程度。

將所有 [數量] 份文件建立為工作資料夾中的獨立檔案，並以清楚的方式命名以便識別。

開始建立之前，請先告訴我你的計畫，確認我沒有遺漏任何內容。
```

## 提示詞 3：行事曆會議準備

**使用情境：** 你的行事曆排得滿滿的，需要了解每位會議對象的背景，但不想逐一手動查詢。

**主要輸入資料：**

* 已啟用行事曆連接器
* 準備的時間範圍（今天、本週等）
* 每場會議所需的資訊類型

**預期產出：** 一份按會議整理的簡報文件，包含每場會議的相關背景。

### 提示詞 3：行事曆會議準備

```
請查看我 [時間範圍 — 例如：「今天」、「本週」、「未來 3 天」] 的行事曆。

針對每場外部會議（略過內部團隊同步會議），建立一份簡報，包含：
- 會議對象（姓名、職稱、公司）
- 其公司業務及近期動態
- 我與對方的過往紀錄（如可存取，請查閱我的電子郵件或先前筆記）
- 可能的議程或對方想討論的內容
- 我可以提出的 2-3 個有見地的問題

請將所有內容整理為單一文件，按時間順序分段呈現每場會議。

請標出任何我可能準備不足或需要額外研究的會議。
```

## 提示詞 4：逐字稿轉策略引擎

**使用情境：** 你擁有大量訪談、Podcast 或通話逐字稿，需要從中提取可執行的洞察。

**主要輸入資料：**

* 包含逐字稿的資料夾
* 你試圖回答的策略問題
* 洞察的目標受眾（你的團隊、主管、客戶等）

**預期產出：** 一份包含綜合洞察與建議的策略文件。

### 提示詞 4：逐字稿轉策略引擎

```
我將授予你存取來自 [來源 — 例如：「客戶訪談」、「Podcast 節目」、「銷售通話」、「專家訪談」] 的 [數量] 份逐字稿。

我需要回答的策略問題：[你的問題 — 例如：「哪些內容主題最能引起受眾共鳴？」、「銷售對話中最常出現哪些異議？」、「成功創辦人有哪些共同點？」]

請逐一閱覽所有逐字稿，並：
1. 找出與我問題相關的模式與主題
2. 摘錄能說明重點的具體引述
3. 注意值得考量的矛盾觀點或少數意見
4. 綜合整理出可執行的建議

建立一份策略文件，包含：
- 執行摘要（2 分鐘內讓我了解重點）
- 按主題整理的詳細發現
- 來自逐字稿的支持性引述
- 根據發現提出的建議行動

此文件的目標受眾是 [受眾 — 例如：「我的行銷團隊」、「執行團隊」、「董事會簡報」]，請適當調整深度與語氣。
```

## 提示詞 5：檔案整理系統

**使用情境：** 你有一個（或多個）雜亂的資料夾，需要整理成可用的結構。

**主要輸入資料：**

* 待整理的資料夾
* 分類方式
* 命名規則

**預期產出：** 重新整理後的資料夾，結構清晰、檔案重新命名。

### 提示詞 5：檔案整理系統

```
我將授予你存取 [資料夾名稱] 的權限，裡面雜亂地存放著 [描述內容 — 例如：「6 個月累積的下載檔案」、「命名不一致的客戶交付物」、「來自多個專案的研究文件」]。

請依以下方式整理此資料夾：
1. [主要排序方式 — 例如：「日期」、「專案」、「客戶」、「內容類型」、「主題」]
2. [次要排序方式（如適用）]

命名規則：[你的規則 — 例如：「YYYY-MM-DD_客戶名稱_文件類型」、「專案名稱_版本_日期」]

規則：
- 視需要建立子資料夾
- 依規則重新命名檔案
- 將重複檔案移至「Duplicates」資料夾（不要刪除）
- 無法分類的檔案放入「Unsorted」資料夾供我審查

開始移動檔案之前，請先告知我你計劃建立的資料夾結構，並取得我的確認。
```

## 提示詞 6：競爭情報報告

**使用情境：** 你需要根據公開資訊和已收集的文件分析競爭對手。

**主要輸入資料：**

* 包含競爭對手資料的資料夾（擷取的網頁、PDF、筆記等）
* 待分析的競爭對手清單
* 要比較的具體面向

**預期產出：** 一份包含比較矩陣與策略意涵的競爭分析文件。

### 提示詞 6：競爭情報報告

```
我將授予你存取 [資料夾] 的權限，其中包含我蒐集的競爭對手資料：[列出競爭對手]。

請從以下維度分析這些競爭對手：
- [維度 1 — 例如：「定位與訊息傳遞」]
- [維度 2 — 例如：「定價與方案規劃」]
- [維度 3 — 例如：「產品功能」]
- [維度 4 — 例如：「內容策略」]
- [維度 5 — 例如：「目標受眾」]

背景說明：我的公司是 [你的公司]，我們 [你們的業務]，主要差異化優勢是 [差異化特點]。

建立一份競爭情報報告，包含：
- 執行摘要與關鍵要點
- 逐一的競爭對手分析
- 顯示我方競爭力的比較矩陣
- 可利用的缺口與機會
- 需應對的威脅

請讓報告具有可執行性——我想知道如何運用這些資訊，而不只是資訊本身。
```

## 提示詞 7：電子郵件開發信生成器

**使用情境：** 你需要根據研究資料為多位潛在客戶撰寫個人化開發信。

**主要輸入資料：**

* 包含基本資訊的潛在客戶名單（姓名、公司、職位）
* 研究資料夾（LinkedIn 匯出資料、公司資訊、筆記）
* 你的提案與期望的行動呼籲

**預期產出：** 針對每位潛在客戶的個人化電子郵件草稿。

### 提示詞 7：電子郵件開發信生成器

```
我需要為 [數量] 位潛在客戶撰寫個人化開發信。

以下是我授予你存取的資料：
- [檔案] 包含潛在客戶名單，含姓名、公司和職位
- [資料夾] 包含每位潛在客戶或公司的研究資料

我的提案：[你的提供內容 — 例如：「免費諮詢」、「產品演示」、「合作機會」]

我的行動呼籲：[你希望對方採取的行動 — 例如：「預約 15 分鐘通話」、「回覆可用時間」、「下載我們的案例研究」]

針對每位潛在客戶，撰寫一封電子郵件，要求：
- 以針對對方的具體內容開場（避免泛泛的恭維）
- 將對方的情況與我的提案連結
- 控制在 150 字以內
- 以清晰、容易執行的行動呼籲結尾

將每封郵件以獨立段落呈現於文件中，並標註潛在客戶的姓名與公司，每封附上主旨列。

不要像推銷員，要像一個認真做過功課的人來書寫。
```

## 提示詞 8：每週營運準備

**使用情境：** 你希望每週一開始就清楚掌握即將到來的事項和需要準備的工作。

**主要輸入資料：**

* 已啟用行事曆連接器
* 電子郵件或通訊連接器（如有）
* 相關專案資料夾

**預期產出：** 一份包含優先事項、準備工作和注意事項的每週簡報。

### 提示詞 8：每週營運準備

```
新的一週開始了，請幫我做好準備。

請查閱：
- 我未來 7 天的行事曆
- 任何需要跟進的最新郵件（如可存取）
- [專案資料夾] 中即將到期的截止日期或交付物

建立一份每週營運簡報，包含：

1. **本週優先事項**
   - 讓這週成功的前 3 件大事
   - 任何不能錯過的硬性截止日期

2. **需要提前準備的會議**
   - 哪些會議需要事前準備
   - 每場會議應準備什麼

3. **待跟進事項**
   - 需要回覆的郵件或對話
   - 我欠對方某些事情的聯絡人

4. **風險與注意事項**
   - 任何可能出問題的事情
   - 時間衝突或行程過滿的日子

5. **建議封鎖的時段**
   - 應該封鎖進行深度工作的時間
   - 建議的準備工作時段

請控制在一頁以內，我要的是快速簡報，不是長篇大論。
```

* 來源內容檔案（逐字稿、文章、影片腳本）
* 目標平台與格式
* 品牌或語氣指南（如有）

**預期產出：** 每個平台皆有備妥的多份內容。

### 提示詞 9：內容再利用流水線

```
我將授予你存取 [來源內容 — 例如：「45 分鐘的 Podcast 逐字稿」、「3,000 字的文章」、「網路研討會錄音逐字稿」] 的權限。

請將此內容再利用，轉化為以下平台的素材：
- [平台 1 + 格式 — 例如：「LinkedIn — 3 則貼文，各自突顯不同洞察」]
- [平台 2 + 格式 — 例如：「Twitter/X — 5 條推文串，呈現關鍵要點」]
- [平台 3 + 格式 — 例如：「電子報 — 摘要附上完整內容連結」]
- [平台 4 + 格式 — 例如：「部落格 — SEO 優化文章，涵蓋主要重點」]
- [平台 5 + 格式 — 例如：「YouTube Shorts 腳本 — 3 段各 60 秒的影片」]

語氣指南：[你的語調 — 例如：「直接且實用，不廢話，口語化但專業」]

每個素材請：
- 針對該平台的格式與受眾調整內容
- 不要只是複製縮短——要真正為該平台重新架構
- 加入相關的主題標籤、行動呼籲或吸引眼球的開頭

所有素材整理在一份文件中，按平台分類。
```

我試圖回答的問題：[你的研究問題]

1. 彙整所有來源的關鍵發現

5. 根據證據提出結論

請在報告中引用來源——引用某一發現時，請說明來自哪份文件。

請針對 [受眾 — 例如：「只會略讀的主管」、「需要細節的技術團隊」、「需要背景說明的外部利害關係人」] 來架構此報告。

我將與 [受眾 — 例如：「我的銷售團隊」、「執行長」、「董事會」] 分享此報告，請適當調整格式。

## 提示詞 12：行銷活動規劃器

**使用情境：** 你需要規劃一個跨平台的完整行銷活動，並產出多種交付物。

**主要輸入資料：**

* 活動簡報或目標
* 品牌資產與指南資料夾
* 歷史活動成效數據（非必要）

**預期產出：** 完整的活動計畫，包含各平台的素材草稿。

### 提示詞 12：行銷活動規劃器

```
我正在規劃一個行銷活動，目標是：[活動目標 — 例如：「產品上市」、「活動推廣」、「潛在客戶開發計畫」、「品牌知名度提升」]

關鍵細節：
- 目標受眾：[對象]
- 時間線：[時間]
- 預算：[預算（如適用）]
- 平台：[管道 — 例如：「電子郵件、LinkedIn、付費社群媒體、內容行銷」]
- 核心訊息：[我們希望受眾知道或採取的行動]

我將授予你存取以下資料：
- [品牌資料夾] 包含我們的指南、資產和語氣文件
- [成效資料夾] 包含過往活動成果（非必要）

建立一份完整的活動計畫，包含：

1. **活動策略**
   - 定位與核心訊息
   - 受眾分眾方法
   - 平台策略及選擇原因

2. **內容行事曆**
   - 各平台的發布時間與順序
   - 相依關係與執行先後順序

3. **素材草稿**
   - 電子郵件文案（主旨列 + 正文）
   - 各平台的社群媒體貼文
   - 廣告文案版本
   - 登陸頁文案

4. **衡量計畫**
   - 各平台的關鍵績效指標（KPI）
   - 判斷活動是否有效的標準

請讓素材草稿盡量接近最終版本——我希望只需少量修改就能直接使用。
```
