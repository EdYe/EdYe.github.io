## [核心摘要]

本片揭示的核心貢獻是：把 Claude 從「問答機」升級為**你的第一位 AI 員工**，甚至是你的「作業系統」。講者 Matt（Mediakix 軟體教學影片製作人）透過語音輸入、脈絡傾倒、例行任務（routines）、技能（skills）與客製化工具，單一年度省下約兩萬美元與每週 12–16 小時的家務時間，解決的痛點是：忙碌的人想把時間拿回來，卻不知道 AI 代理能自主完成到什麼程度。

## [詳細重點整理]

### 1. Claude 即作業系統：省下兩萬美元的私人助理 

Mac 只是技術上的作業系統，功能上，**AI 代理（AI agent）才是作業系統**。操作介面是麥克風按鈕——用意識流口述，讓 Claude 主導執行。實際成果：

- 授權 Claude 存取電子郵件、多年專案、聯絡人、帳單與會計師往來，花一小時腦力傾倒（brain dump）需求後，它主動發現：申報一份稅務表格可省 18,000 美元，且已把給會計師的確認信放進草稿匣。
- 隔天又發現電費是新客戶費率的兩倍，在客戶入口網站點幾個按鈕後電費砍半。
- 心法：給它成果、深度與脈絡，它自己完成；你扮演主管角色，審查成果並給回饋。

**關鍵概念：脈絡傾倒（brain dump）**

### 2. 起點：《一週工作 4 小時》的 DEA 框架 

Tim Ferriss 的核心啟發是「**新富族（New Rich）**」：財富的定義是時間自由與選擇權，而非銀行存款。把時間拿回來的漏斗由上往下：

1. **消除（Eliminate）**——優先處理根本不該存在的事
2. **自動化（Automate）**——能自動化的絕不委派給人
3. **委派（Delegate）**——剩下的才交給其他人（過去是人類，現在是 AI 代理）

與《10X Is Easier Than 2X》呼應：專注獨特能力（unique ability），把泥沼工作外包出去。

**關鍵概念：委派—自動化—消除漏斗**

### 3. 理髮排程自動化：授權式提示詞的範本 

Matt 現場示範把「每兩個月剪一次頭髮」變成 Claude 的定期排程事件，提示詞包含四個關鍵要素：

- 完整需求脈絡（擅長細軟金髮、依評價篩選、可線上預約）
- **「你不需要回來問我的意見」**——預設上 AI 代理害怕做錯，必須明確授權它自主行動
- **「如果你是人類，你會找誰？」**——以人類決策為基準，減少來回提問
- 硬性限制：絕不建立帳號、絕不輸入信用卡資訊（Agent 自設的安全邊界）

它自行產出計畫（先試 A 店、備案 B 店）、查 Google 日曆確認空檔、設成排程任務。

**關鍵概念：授權式提示詞（authorization prompting）**

### 4. 失憶天才：脈絡、任務、格式三段式 

每次對話，Claude 都像「一個失憶的超級天才醒來」，必須重新檢視所有脈絡。因此提示詞應拆成三部分（以巴塞隆納找房為例）：


| 組成              | 內容         | 找房案例                                |
| --------------- | ---------- | ----------------------------------- |
| **脈絡（Context）** | 腦力傾倒所有已知條件 | 社區偏好、預算、養兩隻貓                        |
| **任務（Task）**    | 具體要做什麼     | 去 Idealista、Spotahome 等平台搜尋符合條件房源   |
| **格式（Format）**  | 輸出要長什麼樣    | 匯入試算表，含街區、價格、冷氣、**適配分數（fit score）** |


巴塞隆納房源一小時內會收到 500 則詢問，搶進前 10 則訊息是唯一勝算。Matt 夫妻在試算表中自評分數與理由，任務指令要求 Claude 每輪先讀取上輪回饋、寫入「**學到的偏好（learned preferences）**」，形成**回饋迴圈（feedback loop）**，最終可代表他們自動聯絡房仲。

**關鍵概念：脈絡—任務—格式（C-T-F）提示詞結構**

### 5. 商業應用：把例行行銷變成代理的班表

- 山羊農場比喻：AI 不能幫你照顧山羊，但能監控收件匣、處理飼料帳單、留意價格變動、預約獸醫。
- Sound Toggle（音訊工程師作品集 SaaS）案例：廣告成本高過訂閱收入，關鍵在 SEO 與讓 ChatGPT「談論你」。Matt 設了例行任務去監控競爭對手網站、稽核自家網站內容、研究熱門話題、存取 GitHub 儲存庫、起草文章供他修改後發布。

**關鍵概念：AI 可見度優化（讓 AI 代理談論你的產品）**

### 6. 探索性嘗試 → 技能（Skill）

處理可重複任務的標準流程：先讓 Claude 做一輪**探索性嘗試（exploratory pass）**，找出最佳處理框架，再把成果轉存為一份可重複呼叫的「技能」——如同一份食譜。現場示範為 Calum Johnson Show 建立「來賓研究引擎」：

- 提示詞心法：「研究的深度才是重點」「找出這個頻道自己還沒發現的機會」「有哪些唾手可得的機會」（呼應 Mark Cuban 的問法：有什麼是我沒在做的？）
- Cowork 會提出釐清問題（外聯信用誰的口吻、來賓資格限制、結果何時寄達），並展示自己的待辦清單。

**關鍵概念：技能（skill）＝可重複使用的任務食譜**

### 7. 三種介面的分工：顧問、專案經理、開發者


| 介面          | 角色比喻        | 適用情境                                                  |

**關鍵概念：Claude 即介面（Claude as the interface）**

### 8. 模型分層：探索用強、例行用省 

- 探索性嘗試用最強模型（Matt 當時用 Fable 5.1），因為需要它挖得深、做出新穎的東西。
- 框架與技能建立後，逐級降模型：Opus → Sonnet，直到結果不再驚豔為止。
- 例行任務因為已有「食譜」，低階模型即可勝任，也更省額度。

**關鍵概念：模型階梯（model laddering）**

### 9. 客製工具不燒 token：餐點規劃 PWA 

Matt 家每週花 12–16 小時在「把食物端上桌」的周邊事務（找食譜、依乳糖不耐等限制調整、彙整購物清單、採買、備料）。他用 Claude Code 打造：

- **PWA（漸進式網頁應用程式）**：免 App Store 審核，手機上加圖示即可像原生 App 使用
- 免費跑在 Cloudflare Workers 上，規則為主、少量 AI：每週五晚上 7 點自動產出餐點計畫 JSON，一鍵預填 Mercadona 超市購物車
- 「今天」分頁告訴你今晚煮什麼；煮完評分，回饋進入下週計畫
- 五年前這種超級專屬 App 大概要付開發者約 5 萬美元；市場太小，公司根本不會做，但 Claude Code 讓個人做得到。

**關鍵概念：軟體長尾（long-tail software）——為單一使用者打造的 App**

## [結論與行動建議]

**啟發金句**：「接在『我應該要做＿＿』後面的那件事，其實很可能就是你不該自己做的事。」

**具體行動建議（C-T-F-S 法則）**：

1. **C**ontext（傾倒）：按下滑鼠旁的麥克風按鈕，用語音把生活中最大痛點與全部脈絡倒給 Claude
2. **T**ask（任務）：問它「我們現在馬上能打造什麼，讓我每週拿回一兩小時？」
3. **F**ormat（格式）：指定輸出形式（試算表、草稿信、本機資料夾檔案）
4. **S**kill（成技）：讓它先做探索性嘗試→轉成技能→排成例行任務→每輪給回饋並要求保存

**生活實踐建議**：

- 從那句「我應該要做＿＿」開始盤點——帳單比價、預約類雜務（理髮、獸醫、保養）都是低風險、高授權的首批候選
- 重大決策（換屋、採購、搬家）套用巴塞隆納找房模板：C-T-F 提示詞＋試算表＋適配分數＋學到的偏好欄位，把研究外包給代理
- 行銷與內容經營：設定每週例行任務稽核自家網站、監控競爭對手、挖掘熱門話題，並確保 AI 代理查詢時能正確描述你的產品
- 一旦痛點重複出現且規則明確，就升級到 Claude Code 做成免 token 持續燒的專屬小工具（PWA）
